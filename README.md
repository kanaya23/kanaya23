### 🚀 Flagship Projects

| Project | Tech Stack | Highlights |
|:---|:---|:---|
| **[anonsurf-rs](https://github.com/kanaya23/anonsurf)** | `Rust` `Tor` `GTK4` `nftables` `D-Bus` | Distro-agnostic Rust system daemon replacing Parrot AnonSurf with GTK4/libadwaita GUI, Tor transparent routing, snapshot recovery, and Polkit authorization. |
| **[zero-context-journaling](https://github.com/kanaya23/zero-context-journaling)** | `Python` `AI Agents` `Protocol` | Universal state persistence & micro-step journaling package eliminating agent amnesia and context truncation decay across Antigravity, Claude Code, and Cursor. |
| **[WebICU](https://github.com/kanaya23/WebICU)** | `JavaScript` `Chrome MV3` `rrweb` | Zero-build browser extension capturing user workflows, DOM causality, network streams, and standalone offline HTML snapshots for AI scraper generation. |
| **[Uno-Bayesian](https://github.com/kanaya23/Uno-Bayesian)** | `PyTorch` `Pyro` `Flask` `Python` | Bayesian Neural Network platform for 2v2 UNO strategy learning, variational inference, uncertainty quantification, and real-time training dashboard. |
| **[PixelShifting](https://github.com/kanaya23/PixelShifting)** | `PyTorch` `PyQt5` `Optimal Transport` | Motion field learning framework rearranging source image pixel mass to reconstruct target shapes using multi-scale Sinkhorn and VGG19 perceptual loss. |
| **[Mullion-core](https://github.com/kanaya23/Mullion-core)** | `Playwright` `Node.js` `Caddy` `Netlify` | Cloud-hosted browser automation engine & Chrome extension porting runtime with remote Netlify dashboard. |
